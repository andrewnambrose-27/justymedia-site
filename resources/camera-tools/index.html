Photography Resources

Free camera tools for photographers and videographers.

Whether you are checking a used camera, planning depth of field or working out the storage required for a video shoot, these free browser-based tools provide quick, practical answers without installing additional software.

These tools are built and maintained on 27tools ↗, another independent project by Andrew Ambrose. Selecting a tool will take you to 27tools to use it.

Camera files

Shutter count and camera metadata

Original camera files can contain useful metadata about the camera, lens and exposure settings. Compatible files may also include the camera’s shutter count, which can provide additional context when buying or selling used equipment.

Sony · JPG and ARW

Sony Shutter Count Checker

Check compatible original Sony JPG and ARW files for shutter-count information and view useful EXIF metadata directly in your browser.

Open Sony Tool on 27tools ↗

Canon · CR3

Canon Shutter Count Checker

Inspect an original Canon CR3 file for available shutter-count information while keeping access to the full metadata found inside the image.

Open Canon Tool on 27tools ↗

Nikon · NEF

Nikon Shutter Count Checker

Read compatible Nikon NEF maker-note data to find an available shutter count and inspect useful camera and exposure metadata.

Open Nikon Tool on 27tools ↗

Fujifilm · RAF

Fujifilm Shutter Count Checker

Check an original Fujifilm RAF file for available shutter-count information and inspect the metadata recorded by the camera.

Open Fujifilm Tool on 27tools ↗

File guidance

Use an original camera file

Edited, exported, compressed or social-media images often have their metadata removed. For the best chance of finding shutter-count or EXIF information, use an untouched file taken directly from the camera. Not every camera model records shutter count in a readable field, so a result cannot be guaranteed.

A shutter-count result is one piece of context and does not, by itself, determine a camera’s condition or remaining life.
